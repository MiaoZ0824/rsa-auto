# rsa-auto

**CTF RSA 题型自动判定 + 自动解密。单文件、纯 Python 标准库、零依赖。**

```
git clone https://github.com/MiaoZ0824/rsa-auto.git
cd rsa-auto
python3 rsa_solver.py examples/02_low_exponent/chall.txt   # 立刻跑出一条 flag
```

![CI](https://github.com/MiaoZ0824/rsa-auto/actions/workflows/ci.yml/badge.svg)

---

## 为什么不是又一个 RsaCtfTool

| | rsa-auto | RsaCtfTool | Sage 方案 |
|---|---|---|---|
| 安装 | 下载一个 `.py` 直接跑 | `pip install`（依赖 gmpy2 等） | 装 Sage（数 GB） |
| 依赖 | **纯标准库** | gmpy2 / pycryptodome | Sage |
| LLL / Coppersmith / Boneh-Durfee | **手写实现** | 依赖或缺失 | 用 Sage 自带 |
| 起跑速度 | 秒级 | 秒级（装得上的话） | 几十秒 |
| 题型覆盖 | 33 类 | 40+ 类 | 看具体脚本 |
| 是否执行题面代码 | **否，纯静态解析** | 否 | 否 |

手写 LLL 这件事是它最实际的差别：CTF 现场和别人的机器上，`gmpy2` 编不出来、Sage 装不动的场景太多了。单文件 6700 行，拷过去就能用。

## 快速开始

```bash
python3 rsa_solver.py chall.py            # 解析题目脚本里的 n/e/c
python3 rsa_solver.py data.txt            # 纯文本题面
cat data.txt | python3 rsa_solver.py -    # 从 stdin
python3 rsa_solver.py --n 0x.. --e 65537 --c 0x..
python3 rsa_solver.py chall.py --json     # 给脚本用
python3 rsa_solver.py --list-attacks      # 看支持的 33 类题型
```

Windows：从 [Releases](../../releases) 下载 `rsa_solver_v4.2.exe` 双击即可。可以把题目文件**拖进窗口**，也可以把整段题面**直接粘进去**（粘完连按两次回车）。

### 联网是可选，默认关闭

需要查公开分解库（factordb）时才发数据出去，其余全部本地算：

- 双击 exe → 启动先问一句：`y` 联网 / 回车或 `n` 纯本地 / 大写 `Y`、`N` 记住选择
- 命令行加 `--online` 才联网，加 `--offline` 强制本地
- 交互菜单里输 `set` 随时改，`--forget-net` 清掉记住的设置
- stdin 不是终端时（批处理 / 管道）永远不问、也不联网，不会把脚本卡住

## 支持的 33 类题型

`--list-attacks` 的实际输出，按场景分组：

**参数直接给**

| # | 题型 | 说明 |
|---|---|---|
| 1 | e = 1 | 明文就是密文 |
| 4 | 已知私钥 d | `pow(c, d, n)` |
| 7 | 已知 p、q | 有素因子直接算 φ |
| 8 | 已知 φ | 直接求 d |
| 11 | 已知 dp、dq / CRT 参数 | 不需要分解 n |

**模数结构异常**

| # | 题型 | 说明 |
|---|---|---|
| 12 | n 为素数 | φ = n − 1 |
| 13 | n 为素数 · e 与 n−1 不互素 | 列出全部 e 次根，按可打印性挑 |
| 14 | n 为素数幂 | n = p^k 直接开方 |
| 15 | 模不互素 | 多组模数共享素因子；含链式 n1=pq/n2=qr/n3=rs 全解 + 分段明文拼接 |
| 21 | n 可分解 | 试除 / 费马 / Pollard rho / p−1 / 公开分解库 |
| 24 | 多素数 RSA | n = p·q·r… |

**多组模数关系**

| # | 题型 | 说明 |
|---|---|---|
| 16 | e 未知 · 共享素因子 | 先 gcd 分解，再用已知明文爆破 e |
| 18 | 共模攻击 | 同 n 不同 e；gcd(e1,e2)=g 时先取 m^g 再开 g 次方 |
| 19 | 共模 · e1·e2 = 常数 | 只给乘积，枚举约数对 |
| 20 | 低指数 · 多组广播（Håstad） | CRT 后开方 |

**泄露类**

| # | 题型 | 说明 |
|---|---|---|
| 2 | 整数等式泄露 | 没有 n，只有 `q + q·p³ = A` 这类等式：消元求整根 |
| 9 | 泄露 φ/λ 的倍数（lcm 型） | 见证提取法劈开 n |
| 10 | 素因子偏移泄露 `(p±a)(q±a)` | 先还原 p+q 再解二次方程 |
| 17 | 模下幂泄露 `P ≡ p^k mod n` | `gcd(P, n)` 直接劈开 |
| 22 | 泄露 p²+q² | `(p+q)² = z + 2n` |
| 23 | 两段明文（和 / 立方和） | 解出两段再拼回 |
| 31 | 多组泄露 + nextprime 线性组合 | 逐组反解后按题面线性组合还原真模数 |

**关系反解**（p、q 不给，只给关系）

| # | 题型 | 说明 |
|---|---|---|
| 3 | 只给 d、没给 n（p、q 挨着 / nextPrime 型） | `(p+q−2)² − 4φ = (p−q)²` 附近试几格 |
| 5 | 已知 p±q 关系 | 和 / 差 / 平方差 / 平方和，联立 n 反解 |
| 6 | p±q 两个未命名大数（无 n） | 逐对试，素数校验 + 解密回代确认 |

**格攻击 / 启发式**

| # | 题型 | 说明 |
|---|---|---|
| 25 | 低加密指数 · 小明文 | `m^e < n` 直接开方 |
| 26 | 已知明文部分（Coppersmith） | 已知 m 的部分比特或前缀 |
| 27 | Rabin（e = 2） | 4 个候选根 |
| 28 | 已知 p 高位（Coppersmith） | 恢复低位 |
| 29 | Franklin-Reiter 相关消息 | 线性相关明文的密文做多项式 GCD |
| 30 | Wiener 攻击 | d < n^0.25/3，连分数 |
| 32 | e 与 φ(n) 不互素 | 剥公因子降到 m^g，再分模开根 + CRT |
| 33 | Boneh-Durfee（d < n^0.292） | 小私钥指数格攻击，启发式 |

变量名识别放得比较宽：`p_q_sum`、`pq_sum`、`sum_pq`、`s`、`hint`、`p_q_diff`、`delta`、`diff`、`p_sub_q`、`p2_minus_q2` 都认；写成 `s = p + q` 再 `print(s)` 的认；题面里一句话写 `p - q = 数字` 也认。

## 已知局限（先说清楚）

- **纯静态解析，不执行题面代码。** 好处是安全、不依赖题目里的 `Crypto` 库；代价是动态算出来的值（`n = p*q` 后面没 `print`）抓不到 —— 这种题要在题面里把 `n`、`e`、`c` 打印出来。`samples18/s06`、`samples19/s03` 是这类写法的代表。
- **Coppersmith 和 Boneh-Durfee 是启发式尝试**，格维度、参数、边界都会影响，不保证 100% 命中。真实比赛里失败率不高但也不是零，判「未命中」不代表题目无解。
- **只覆盖 RSA 类题型。** AES / ECC / 哈希长度扩展这些不做。
- **多段链式求解**会枚举未知小整数，默认上限 40 万（`--enum-max` 可调），太低会漏、太高会慢。
- 不是自动化框架：不替你去连题目环境、不解析 flag 格式以外的协议，就是「给题面 → 出明文」。
